# Third-party notices

## Libraries

The Go modules and npm packages the editor depends on keep their own licenses, listed in `go.mod` and
`frontend/package.json` and shipped with each package.

The code Meld ported from [Benilla](https://github.com/samwhosung/benilla) (particles, ribbons, the
client's clouds and sky, WMO rooms, liquids, ground effects) went with the WoW features it drew
(3dgame #59, #61), so its notice is no longer needed here.
